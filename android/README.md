# TaskHub Android 0.2

Kotlin + Jetpack Compose. Собственные аккаунты и FastAPI; Telegram не нужен.

## Обновление уже клонированного проекта

Из корня репозитория проверь ветку и сохрани локальные правки **до** pull:

```bash
git status
git stash push -m "local-before-taskhub-0.2"
git switch feature/android-api
git pull --ff-only origin feature/android-api
```

Stash сохраняет локальные изменения в отслеживаемых файлах. Не выполняй
`stash pop` автоматически: правки IP и ошибки smart cast уже учтены в новой версии.
Посмотреть сохранённые правки можно через `git stash list` и `git stash show -p`.
Если Git сообщает о конфликте, остановись и разреши его, не используй force/reset.

## Backend

В первом терминале из корня проекта:

```bash
source venv/bin/activate
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

При отсутствии окружения сначала создай его: `python3 -m venv venv`.
Не запускай `main.py` — это старый бот. Backend запускается без `BOT_TOKEN`.
API и SQLite должны быть доступны всё время, когда нужно входить или менять данные.

## APK

Android Studio или JDK 17 + Android SDK с API 37. Gradle Wrapper уже в репозитории.
Из корня проекта, во втором терминале:

```bash
cd android
./gradlew assembleDebug testDebugUnitTest
open app/build/outputs/apk/debug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
Передай файл на телефон и разреши установку этому источнику.
Повторная сборка на том же компьютере обычно сохраняет debug-подпись, поэтому
устанавливай поверх предыдущей версии.

В GitHub Actions можно скачать артефакт `taskhub-debug-apk` после успешной сборки.
CI использует временную debug-подпись: такой APK может не устанавливаться поверх
локальной сборки с другой подписью. Удаление приложения удаляет его локальную
сессию/кеш, но не данные аккаунта на сервере; перед удалением убедись, что помнишь
логин и пароль. Для регулярных релизов нужен свой постоянный ключ подписи, вне Git.

## Подключение и аккаунт

1. На экране входа укажи URL сервера; текущий отладочный адрес по умолчанию:
   `http://192.168.10.4:8000/`.
2. Для эмулятора используй `http://10.0.2.2:8000/`. Для телефона — LAN IP Mac.
3. Mac и телефон должны быть в одной сети. С телефона сначала проверь `/docs`.
4. Выбери «Создать аккаунт». Логин: 3–32 символа a–z/0–9/_. Пароль: 10–128 символов.
5. После входа создай свои задачи и расписание. Сменить пароль/выйти можно в настройках.

Адрес сохраняется в приложении. Чтобы поменять сервер, выйди из аккаунта; токен
старого сервера не отправляется на новый. Значение по умолчанию для сборки можно
переопределить без редактирования исходников:

```bash
./gradlew assembleDebug -PAPI_BASE_URL=http://192.168.10.4:8000/
```

В release принимается только HTTPS; открытый HTTP включён **только в debug manifest**.
Не передавай реальные публичные учётные данные по HTTP. Не публикуй локальный
отладочный сервер напрямую в Интернет.

## Напоминания и офлайн

- Уведомления настраиваются внутри приложения; сначала включи напоминания о парах.
- В настройках нажми «Разрешить уведомления Android».
- Для точного времени на Android 12+ отдельно разреши «Точные напоминания».
  Без разрешения используются неточные будильники, которые Android может задержать.
- Ноль минут означает уведомление в момент начала пары.
- Время и чётность вычисляются в выбранной IANA-зоне по ISO-неделям.
- Сохранённые пары могут напоминаться без сети. После перезагрузки будильники
  восстанавливаются. Принудительная остановка приложения средствами Android
  приостанавливает его фоновые действия до следующего открытия.
- Фоновая синхронизация запрашивается каждые 15 минут через WorkManager; Android
  может откладывать её ради батареи/сети. Открытый экран обновляется раз в минуту.
  Изменения с другого устройства не являются мгновенными push-обновлениями.
- После сетевой ошибки показывается последний сохранённый снимок. Офлайн-редактирования
  и очереди изменений нет: создание/редактирование требуют backend.
- Сессия действует 30 дней. При выходе локальные данные и напоминания очищаются;
  при смене пароля остальные серверные сессии отзываются.

## Проверки

```bash
./gradlew assembleDebug testDebugUnitTest lintDebug
```

Unit tests: сериализация nullable PATCH-полей, ru/en/kk, нормализация URL,
чётность на границе года, часовой пояс, переход через полночь, нулевой интервал.
Дополнительно проверь на телефоне: регистрация/повторный вход, CRUD всех полей,
конфликт двух пар, запрет доступа второго аккаунта, смена языка, отказ в разрешениях,
режим полёта, выход и перезагрузка. Unit tests не заменяют такую проверку.
